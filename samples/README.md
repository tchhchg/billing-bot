# 样例账单放这里（P2 用）

P2「导入解析器」需要真实的导出文件才能定稿列映射。**放文件前请先脱敏**。

## 放哪几个文件

| 文件名（请照抄） | 来源 |
|---|---|
| `alipay.csv` | 支付宝「开具交易流水证明 → 用于个人对账」 |
| `wechat.csv` | 微信「账单 → 常见问题 → 下载账单 → 用于个人对账」 |
| `bank.xlsx` 或 `bank.csv` | 手机银行导出的交易明细（哪家银行都行，文件名后缀告诉我行名更好，如 `bank-cmb.xlsx`） |

把文件直接放在本目录（`billing-bot/samples/`）即可，我会自己读。

## 脱敏清单（发我之前逐条过一遍）

- [ ] 真实姓名 → `张三`
- [ ] 银行卡号 / 账号 → `尾号1234`
- [ ] 完整商户名 → `商户A`、`商户B`……（**同一商户要保持一致**，否则我无法验证「同商户归组」逻辑）
- [ ] 订单号 / 流水号 → `SN0001`、`SN0002`……（保持唯一且不重复，用于验证导入幂等）
- [ ] 手机号、身份证、邮箱、地址 → 一律替换
- [ ] **金额保留真实数值**（我需要真实的数值形态来验证千分位、正负号、退款行）
- [ ] 备注 / 商品说明：可保留文字结构，敏感内容替换掉

## 两个不要

1. **不要用 Excel / WPS 打开后另存**。会改写编码与列格式，我要的是平台导出的原始文件。正确做法：解压出 CSV 后直接复制过来。
2. **不要手工删行**。行数少没关系（几十行足够），但结构要完整，包括表头前的说明行、汇总行——那些正是解析器最容易踩坑的地方。

## 解压密码从哪来

- 支付宝：发送后**支付宝 App 内会收到一条消息**，里面有解压密码。
- 微信：发送后**微信内会收到通知/消息**，里面有解压密码。
